# BSFRF/NMFS survey selectivity analysis

This protected upstream analysis estimates size-based survey-efficiency information from paired BSFRF Nephrops and NMFS bottom-trawl observations for Snow and Tanner crab, retaining species and sex identifiers. It includes empirical, logistic, and bootstrap summaries plus the scripts needed to recreate them.

Scripts are in `scripts/`; tables, fitted objects, and figures are retained in this directory. These files must not be removed merely because a downstream population-model version does not use the resulting priors.
